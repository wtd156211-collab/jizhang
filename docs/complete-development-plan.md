# 公司记账系统完整功能开发计划

> 版本日期：2026-10-12
> 正式客户端：Web + Flutter 手机 App。Flutter App 同时支持 Android 和 iOS，首版优先验证 Android。
> 本文只描述功能范围和需要实现的内容，不描述具体技术实现。

## 一、产品范围

系统面向单一公司内部使用，Web 和手机 App 共用同一套账号、权限、账目、审核和统计规则。

### 正式客户端

- Web：面向管理员、会计和日常财务工作台。
- 手机 App：面向 Android 和 iOS，适合快速记账、拍照上传和移动审核。

### 不再扩展的客户端

- 微信小程序只保留历史兼容代码。
- 后续新功能只开发 Web 和 Flutter 手机 App。

### 第一版不包含

- 多公司注册和 SaaS 租户隔离。
- 公开注册。
- 多币种和汇率换算。
- 银行流水自动接入。
- 会计凭证、借贷分录和结账。
- 采购、库存、销售和 CRM。
- 自动审批。
- OCR 识别后自动入账。

## 二、阶段 0：系统基础

### 共用功能

- 系统首页和基础页面框架。
- 登录、退出和登录状态失效处理。
- 当前用户信息展示。
- 权限不足提示。
- 页面加载、空数据、错误和重试状态。
- 重要操作记录。

### Web 端

- 登录页。
- 工作台主框架。
- 左侧导航。
- 当前用户信息。
- 根据权限显示和隐藏菜单。

### 手机端

- 登录页。
- 首页框架。
- 当前用户信息。
- 登录状态失效处理。
- Android 和 iOS 保持一致的业务行为。

## 三、阶段 1：账号、权限和基础配置

### 共用功能

- 管理员创建员工账号。
- 修改员工基本信息。
- 启用和禁用账号。
- 禁用账号后立即失效。
- 用户名和密码登录。
- 角色和权限控制。
- 部门管理。
- 项目管理。
- 收入分类管理。
- 支出分类管理。
- 支付方式管理。
- 资金账户管理。
- 配置启用和停用。
- 账号和配置操作记录。

### Web 端

- 用户列表。
- 新建用户。
- 编辑用户。
- 启用或禁用用户。
- 角色分配。
- 用户状态筛选。
- 部门、项目、分类、支付方式和资金账户设置。

### 手机端

- 登录和退出。
- 当前账号信息。
- 当前权限展示。
- 记账时选择可用分类、支付方式和资金账户。
- 账号禁用或登录失效提示。

> 复杂的用户管理和系统配置以 Web 端为主，手机端不重复制作完整后台页面。

## 四、阶段 2：手工记账和附件

### 共用功能

- 创建收入记录。
- 创建支出记录。
- 填写摘要、发生日期和发生时间。
- 选择分类、支付方式和资金账户。
- 填写总金额。
- 填写多条账目明细。
- 校验明细合计和总金额一致。
- 保存草稿。
- 编辑草稿。
- 删除未提交草稿。
- 提交审核。
- 查看自己的账目。
- 查看账目状态和退回原因。

### 账目状态

- 草稿。
- 待审核。
- 已退回。
- 已入账。
- 撤回重审。
- 已作废。

### 附件功能

- 上传图片。
- 上传 PDF。
- 设置一张主票据。
- 添加补充附件。
- 附件数量限制。
- 附件大小限制。
- 文件类型检查。
- 附件预览。
- 附件下载。
- 删除附件。
- 上传失败重试。
- 附件访问记录。

### Web 端

- 账目列表。
- 收入和支出筛选。
- 日期筛选。
- 分类筛选。
- 金额筛选。
- 新建账目。
- 编辑草稿。
- 文件选择上传。
- 图片和 PDF 预览。
- 账目详情和明细查看。
- 提交审核。
- 查看退回原因。

### 手机端

- 快速记账入口。
- 分步填写账目。
- 最近账目列表。
- 草稿继续编辑。
- 账目详情。
- 拍照上传主票据。
- 从相册选择图片。
- 从文件中选择 PDF。
- 上传进度和失败重试。
- 提交审核。

## 五、阶段 3：OCR 识别和人工核验

### 共用功能

- 上传票据后创建识别任务。
- 识别金额。
- 识别日期。
- 识别商户或摘要。
- 识别可用的票据编号。
- 将识别结果回填到账目表单。
- 用户手动修改识别结果。
- 用户确认识别结果。
- 识别失败重试。
- 无法识别时转为手工记账。
- 识别结果不能直接自动入账。

### Web 端

- 查看识别任务。
- 查看识别结果。
- 修改识别字段。
- 确认并创建草稿。
- 识别失败提示和重试。

### 手机端

- 拍照后发起识别。
- 识别进度展示。
- 识别结果确认页。
- 手动修正识别字段。
- 识别失败后进入手工录入。

## 六、阶段 4：审核、退回、重提和作废

### 共用功能

- 待审核列表。
- 查看账目详情、明细、附件和提交人。
- 查看发生日期、金额和当前状态。
- 通过审核。
- 退回账目。
- 退回原因必填。
- 管理员自审。
- 查看审核历史。
- 查看审核人和审核时间。
- 查看状态变化记录。
- 处理重复操作。
- 处理多人同时修改产生的冲突。

### 撤回和作废

- 已入账记录撤回重审。
- 撤回原因必填。
- 撤回后重新编辑。
- 管理员作废已入账记录。
- 作废原因必填。
- 作废前二次确认。
- 作废记录不再进入有效金额统计。
- 历史记录和审核轨迹保留。

### Web 端

- 审核中心。
- 待审核、已通过、已退回筛选。
- 审核详情。
- 通过按钮。
- 退回按钮。
- 退回原因输入。
- 审核历史时间线。
- 账目详情中的提交、撤回和作废操作。

### 手机端

- 待审核列表。
- 审核详情。
- 查看附件。
- 通过。
- 退回。
- 填写退回原因。
- 查看审核历史。
- 本人账目撤回。
- 管理员作废。

## 七、阶段 5：数据屏、报表和导出

### 共用功能

- 收入总额。
- 支出总额。
- 净额。
- 待审核数量。
- 按分类统计。
- 按日期统计。
- 日报表。
- 周报表。
- 月报表。
- 自定义日期报表。
- 收入和支出筛选。
- 分类筛选。
- 有效账目统计。
- Excel 导出。
- 导出权限控制。
- 导出操作记录。

已退回、撤回和作废的记录不能计入有效金额。

### Web 端

- 数据总览首页。
- 收入、支出和净额卡片。
- 收支趋势图。
- 分类统计图表。
- 报表明细。
- 日期范围选择。
- Excel 下载。

### 手机端

- 首页金额概览。
- 本月收入和支出。
- 简单分类统计。
- 日期范围查询。
- 移动端报表列表。
- Excel 导出触发。

手机端以清晰、快速查看为主，不复制 Web 端复杂图表布局。
